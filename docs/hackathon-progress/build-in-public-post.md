# Build-In-Public Post Draft

I built Quipu, a local-first personal memory engine prototype.

The first version is intentionally focused: a blank Canvas for what matters now,
and an Ingest flow for notes, deadlines, files, and project context. Capture
something once, review any proposed reminder or preference, then ask questions
back against your own saved memory with source citations.

For the hackathon prototype, local ingest and Canvas run in one app. The
direction is local-first ingest that can later sync structured memory packets to
a hosted or self-hosted Canvas.

Codex helped me move from product notes to a working prototype, README, and
submission assets quickly while keeping the app honest about what is AI-backed:
if no OpenAI-compatible provider is configured, Quipu saves raw drafts but does
not fake summaries or reminders with rules.
